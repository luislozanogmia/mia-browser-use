Ghost

Browse the web together with Mia and your friends. Ask about anything on a page, and let Mia do tasks for you.

This installs Ghost for Google Chrome. It takes about a minute, and you don't need to install anything else first.

Mia uses your own Anthropic account through Claude Code. If it is missing, the installer downloads unmodified Claude Code 2.1.281 from Anthropic and verifies its checksum. Claude Code and Claude are provided by Anthropic under Anthropic's terms; Mia does not guarantee Anthropic's service or model output.
